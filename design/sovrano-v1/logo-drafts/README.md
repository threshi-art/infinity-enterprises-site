# INFINOIR wordmark drafts (round 1)
Status: DRAFT explorations, for reference only. Not for shipping.
Font: Bodoni Moda (SIL Open Font License), display optical size, weight 600 (C uses 450, wide tracking).
Lettering is set in type, not AI-generated. The infinity line in B is a drawn lemniscate (make.py).
Files: 2400x900 PNGs. A is classic ink on ivory. B puts the infinity line through the O, in ink/ivory on solid and transparent backgrounds. C is wide-tracked ivory on noir.
Palette: ink #0E0E10, ivory #F4EFE6.
Known issue: hairlines and the infinity line disappear below about 220px wide (see size-test.png). Small uses need a sturdier cut or a monogram.
Regenerate with: python3 make.py
