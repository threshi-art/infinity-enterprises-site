• One player for the whole site, cross-fades between rooms
• Accessible name and aria-pressed state on toggle button
• Visible focus indicator (2px solid #c77c55 outline)
• Audio files loaded only after sound is enabled
• Player pauses when tab is hidden
• Each room has: loop (~20-30s, seamless AAC/MP3) + short entry sound
• All assets CC0 or original, loudness matched, manifest with sources
