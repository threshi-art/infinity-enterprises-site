# Tech Lounge — Afterimage Workshop

**Status:** Design-only desk bible. This does not alter the current `/tech-lounge` route or authorize a runtime change.

## Baseline and reconciliation

The existing live and `studio` Tech Lounge is a valuable preservation baseline: an ink-black and aubergine after-hours salon with warm ivory display type, amber/violet accent, vintage computing, semiconductor macro texture, reading shelves, and archive media. It should not be replaced by a generic technology dashboard.

Legacy [#47](https://github.com/threshi-art/infinity-enterprises-site/issues/47) describes a colder, circuit-grid direction from an earlier public-map phase. Preserve it as exploratory input, not current route authority.

> **Resolution:** retain the warm, tactile lounge as the emotional arrival. Add cold circuit precision only in the information and provenance layer.

![Tech Lounge: Afterimage Workshop](studies/vd-02-tech-lounge-afterimage-workshop.jpg)

## Editorial premise

Technology is object, system, labor practice, cultural force, and source of strange futures. Tech Lounge may enjoy invention without worshipping it.

## Visual grammar

| Layer | Direction |
| --- | --- |
| Arrival | Ink black and smoky aubergine; tangible machine or workbench; one strong image; a room, not a dashboard. |
| Information | Hard modular grid; clear source cards; compact mono labels for metadata/state only; precise spacing. |
| Palette | Obsidian `#080a0d`; aubergine `#171320`; warm paper `#f1ebe3`; signal amber `#e9bb82`; circuit cyan `#a9eaf5`; optional ultraviolet `#6f4a87`. Cyan is an instrument color, not the page. |
| Type | Editorial serif for a question/essay title; clean grotesk for hierarchy; mono for provenance, state, technical detail. |
| Image grammar | Original macro hardware, archival-computing texture, workbench scenes, nocturnal infrastructure, and clearly marked conceptual art. |
| Motion / sound | Discrete scan or settle; reduced-motion safe; sound opt-in; never required to understand the page. |
| House Figure | Optional visual observer only. Never a factual technical authority, security expert, source, or incident dramatization. |
