## Operating boundaries

- Manus begins source work only from a posted **Ready** card with an exact editable/read-only file boundary.
- Each implementation slice ends in one focused pull request into `studio`.
- A non-author reviewer must review the exact PR head before merge.
- Codex/Seraphim retains the existing `main` release and actual OpenAI/ChatGPT Site publication lane until Chris records a ratified change.
- No file here authorizes a production change or supersedes a recorded Chris or parent-owner decision.
- The charter materials are **proposed only**. They do not grant Manus `main`, ChatGPT Sites production, production-migration, self-approval, or unrecorded merge authority.

## Maintenance

Update this workspace only when the team adopts a substantive change to roles, gates, or release policy. Do not put secrets, personal data, browser/session data, unpublished editorial material, machine-specific notes, or volatile status dumps here.
