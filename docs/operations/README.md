# Operations records

This directory contains **repository-native operating records** that support the SAVRONO program without changing the public site, Worker, release configuration, or ChatGPT Sites publication state.

| Record | Use | Authority boundary |
| --- | --- | --- |
| [SAVRONO Activation Board](SAVRONO-ACTIVATION-BOARD.md) | A compact visual-ready GitHub operating view for the next source slice, the serial follow-on, named hold gates, and Ready/Blocked reply formats. | GitHub Issues, pull requests, checks, and exact-head reviews remain authoritative. The board is not live telemetry or a release command surface. |

## Read this before acting

- A queue position is not a Ready card.
- A focused branch or PR is not a release.
- A `studio` or `main` merge is not a ChatGPT Sites publication.
- Parent owners post the Ready/Blocked contract. Manus maintains the Ready / Next / Planned orientation.

For current program architecture and operating controls, use the [Infinity Enterprises Control Tower Wiki](https://github.com/threshi-art/infinity-enterprises-site/wiki/Control-Tower). After an operations record is reviewed and merged to `studio`, the Wiki may link to its stable `studio` path without duplicating its mutable status content.
